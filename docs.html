Getting Started

Welcome to Tan Compose! Build reusable web components with declarative syntax.

<h3>Installation
npm install tan-composecode>

Basic Usage

<div class="code-block"> import { describe, build } from 'tan-compose'; const button = describe({ tag: 'button', template: 'Click me!', styles: { padding: '10px 20px', backgroundColor: '#007bff', color: 'white', border: 'none', borderRadius: '4px' }, action: () => alert('Button clicked!') }); build('my-button', button);
