@ra9/tan-compose-icons

Icons, every page can use.

44 commonly-needed icons drawn from the Lucide set, packaged as a single <tc-icon> custom element. Inline SVG, inherits currentColor, no font file, no sprite sheet, no build step.

$ deno add jsr:@ra9/tan-compose-icons
<tc-icon name="...">

Basic usage

Import once, drop the tag in any HTML. Pass the icon name as an attribute.

import "@ra9/tan-compose-icons"; <tc-icon name="check"></tc-icon> <tc-icon name="search" size="32"></tc-icon>
props

Props

All five attributes are optional except name.

Prop Default Notes
name — One of 44 icon names. Unknown names render a small placeholder square with a ? mark so missing icons are visible.
size 1em Any CSS length: 16, 20px, 1.2em, 2rem. Applies to both width and height.
stroke currentColor Stroke color. By default the icon inherits color from the surrounding text — change CSS color on a parent and the icon follows.
fill none Fill color. Most Lucide icons are stroke-only outlines, so the default is correct; override for filled-style variants.
title (empty) Accessible name. When set, the SVG gets role="img" + aria-label; when empty, it gets aria-hidden="true" (decorative).
size

Sizing

size takes any CSS length. Omit it and the icon sizes with the surrounding text (1em).

currentColor

Color via currentColor

The default stroke is currentColor, so a parent's CSS color wins. This makes icons drop cleanly into text, buttons, links, badges — anything with a foreground color.

Default Accent Danger Success Muted
<span style="color: tomato;"> <tc-icon name="alert-circle"></tc-icon> </span> <tc-button variant="primary"> <tc-icon name="download"></tc-icon> Download </tc-button>
title

Accessibility

Pass title when the icon carries meaning (icon-only buttons, status indicators). Leave it empty when the icon is decorative and an adjacent text label already describes it.

Saved
// icon-only button — needs an accessible name <button aria-label="Delete item"> <tc-icon name="trash" title="Delete"></tc-icon> </button> // decorative — text already says "Saved" <span><tc-icon name="check-circle"></tc-icon> Saved</span>
